## Overview

The course materials behind my teaching, built for students who reason about **institutions and
behavior** rather than code. Each notebook pairs a method with worked, runnable examples, spanning
statistics, supervised and unsupervised learning, network analysis, text, and time series.

## Contents

**Foundations**
- `Intro_Python_23.ipynb` — Python for data analysis.
- `1. Estadística.ipynb` — statistics and inference fundamentals.

**Supervised learning**
- `Supervised_Classification_23.ipynb` — classification models and evaluation.
- `2. Pipelines & CV.ipynb` — ML pipelines and cross-validation.
- `99. Tutorial Optuna.ipynb` — hyperparameter optimization with Optuna.

**Unsupervised learning**
- `Unsupervised_23.ipynb` — overview of unsupervised methods.
- `3. Cluster Analysis.ipynb` / `cluster_analysis.ipynb` — clustering.
- `4. Feature Reduction.ipynb` — dimensionality reduction and feature selection.

**Networks & text**
- `3. Social Network Analysis.ipynb` — social network / graph analysis.
- `grafos_mundial1122.ipynb` — graph analysis applied to the 2022 World Cup.
- `99. Análisis de Texto.ipynb` — text analysis and NLP.

**Time series**
- `FBprophet.ipynb` — forecasting with Prophet.

**Class sessions**
- `Clase_3.ipynb`, `260924_class.ipynb`, `260924_class_v2.ipynb` — dated in-class walkthroughs.
- `test_dashboard.py` — small dashboard demo.

## Tech Stack

Python · scikit-learn · pandas · NetworkX · Prophet · Optuna · Jupyter.
